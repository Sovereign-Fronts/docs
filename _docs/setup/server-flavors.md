Sovereign Fronts servers can use different **flavors**, each offering its own way to customize the server and support mods. Cinnamon is the official flavor, but other flavors can offer different tools and features for developers.

## Which Flavor Should I Use?

### I just want to play with mods

Choose a flavor based on the mods you want to use. Cinnamon is the official option, with its own modding ecosystem and support through the official launcher.

### I want to develop mods or customize my server

Each flavor provides its own APIs and tools for modifying server behavior and developing mods. Your choice determines what you can build and which existing mods your server can support. You can also create your own or modify the cinnamon flavor if you need capabilities that existing ones don't provide.

## Cinnamon

Cinnamon is the official flavor of Sovereign Fronts. It provides the standard server implementation and the official API for Cinnamon mods. The official launcher is based on Cinnamon.
